## 本地项目依据与优先级

1. `Project-Astra/游戏概念文档.md`：AI 统治、人载探针、单人廉价舱、延迟通信。
2. `Project-Astra/PROJECT_MEMORY.md`：四面墙、固定中心观察、既有操作与技术版本。
3. `Project-Astra/美术/Project_Astra_美术基调与资产制作规范_v1.0.md`：色板、材质和几何方向。
4. `Project-Astra/美术/样板首版_保留锈蚀/README.md`：更新的用户确认，保留锈蚀；比早期「净化表面」建议优先。
5. `Project-Astra/3D Demo/UnityProject/ProjectSettings/ProjectVersion.txt` 与 Packages/manifest.json：实际 Unity 版本与模块。
6. 已查看 A_after.png 和两张参考游戏截图，并阅读 WornMetal Shader、CabinBuild、模型生成脚本中的屏幕定义。
