# ASTRA · V3 异种角色扩展

以第一版信号档案 Demo 为基础，保留三名原有人类角色、舱室终端、灰绿旧漆、低模块面和字幕式演出。新增三个独立档案：站立外星人「弦」、半兽人「砾」、四肢爬行外星人「伏」。新增模型沿用第一版的原创建模方法，不依赖第二版的人物包。

双击 **[Launch.cmd](Launch.cmd)** 运行，默认展示站立外星人。按 **4、5、6** 直接查看新人物；按 **1、2、3** 返回原有人物。需要保留整个 Build 文件夹。

| 通道 | 人物 | 演示重点 |
|---|---|---|
| 1–3 | 林、赫、余 | 原有角色与回信分支 |
| 4 | 弦 / 318 · 站立外星人 | 高瘦体型、长颅、颈侧结构、工作服；站立对话、手势、视线和眨眼 |
| 5 | 砾 / 509 · 半兽人 | 宽肩、厚下颌、短獠牙和修补工作服；解释、摇头、胸前手势 |
| 6 | 伏 / 640 · 四肢爬行外星人 | 横向躯干、四目、四只承重肢、尾部和回收设备；短程爬行、低头观察、停驻 |

## 操作

| 操作 | 按键 |
|---|---|
| 选择角色档案 | 1–6 或上方六个通道按钮 |
| 显示整句 / 继续 | Space；必要停顿结束后才能进入下一句 |
| 自动播放 | A 或右上角按钮 |
| 胸像 / 全身（爬行体为两个全体构图） | B |
| 爬行 / 停驻 | C，仅影响爬行体 |
| 暂停、重播 | P / Esc、R |
| 复古 / 清晰、静音 | V、M |
| 演出检查、截图 | F1、F12 |

爬行体使用低机位三分之四构图，B 切换为更偏侧面的全身观察。暂停提示放在画面边缘，可直接检查骨架姿态。字幕窗口和视频长宽比一致，避免全身画面在 UI 内再次裁切。

## 编辑与复现

- [UnityProject](UnityProject)：Unity 2022.3.62f1，Built-in；场景 `Assets/Performance/Scenes/Performance.unity`。
- [Source/Astra_Six_Species.blend](Source/Astra_Six_Species.blend)：六个带骨架模型；对象分开排列，可单独修改。
- [Tools/build_species.py](Tools/build_species.py)：生成三个新角色并重新导出完整六人组。
- [Docs/07_第一版异种扩展.md](Docs/07_第一版异种扩展.md)：造型、步态、架构、世界观边界和验收方法。
- [异种扩展说明.html](异种扩展说明.html)：离线查看说明与真实播放器截图。

```powershell
.\Rebuild.ps1
.\Rebuild.ps1 -RegenerateCharacters
.\Verify.ps1
.\VerifySpecies.ps1
```

新增档案属于美术与演出探索，尚未并入 Project-Astra 正式设定。爬行采用适用于平地档案场景的程序化支撑与两段 IK，没有导航、攀墙、战斗或复杂地形适配。口型是文字节奏驱动，不是真人配音或音素同步。模型保持第一版的刚性低模骨骼风格。

本版位于 `Demo/V3`；[V1](../V1) 和 [V2](../V2) 可分别运行。
