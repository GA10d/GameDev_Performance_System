# 演出模板

更新日期：2026-09-27。

在时间轴或演出树窗口点击 **新建演出**，现在会先打开模板选择窗口。

| 模板 | 自动生成的内容 | 需要填写 |
| --- | --- | --- |
| 单人来电 | 开场 → 结束语 → 结束；单人中景、说话动作和背景 | 一位主讲人、场景、开场台词、结束语 |
| 双人对话 | 两位角色轮流说话 → 结束；双人镜头和过肩镜头、主讲人说话与倾听者待机 | 两位不同角色、场景、双方台词 |
| 交互问答 | 开场与提问 → 两个选项或超时 → 各自回应 → 三个结束节点 | 主讲人、场景、开场、提问、选项文字、三种回应、等待时间 |
| 纯播报 | 一段播报 → 自动结束；单人中景和说话动作 | 主讲人、场景、播报内容 |
| 空白演出 | 空单元 → 结束，自动设好入口 | 名称和素材库 |

## 制作第一段模板演出

1. 点击 **新建演出**，选择 **交互问答**。
2. 填写演出名称，在下拉列表中选主讲人和场景。
3. 替换开场台词、提问、两个选项及各自回应。可以直接用默认内容先体验。
4. 配置等待回复秒数，以及玩家没有选择时的回应。
5. 点击 **创建演出**，回到时间轴。点击 **运行预览** 即可实际选择分支。
6. 需要精调时，修改时间轴或点击 **演出树**。生成后的内容都是普通演出数据，不受模板限制。
7. 完成后点击 **保存** 或 **导出到游戏**，沿用现有的资产生成和导出流程。

如果已有未保存草稿，只有点击 **创建演出** 时才会询问如何处理它；打开模板窗口、切换模板、取消不会替换当前演出。切换模板会保留各模板当前输入的内容，便于比较。

## 自动处理的内容

- 角色引用、动作与镜头目标自动填写，不用手填 `actor0` 等内部标识。
- 台词默认每秒显示 18 个字符，完整显示后停留 1.2 秒。段落时长按文本长度计算，人物、背景和镜头覆盖整段内容。
- 问答的倒计时从提问出现时开始，期间角色切到待机。两个回复和超时出口均已连接；超时会播放单独的回应。
- 双人对话保持角色位置一致，轮换说话角色和镜头目标。
- 模板实例有独立的演出树和单元。公共角色与素材库复用，生成模板不会改动原角色或已有演出。
- 本次模板面向人类、直立外星人和半兽人。四足角色仍可通过空白演出自行编排。
- 生成字幕与角色动作，不自动生成配音。

模板保存在内存草稿中，沿用自动恢复；保存或导出时才创建正式演出资产。导出后的游戏接入方式没有变更。
