# V2 捏人与演出设计

## 目标与视觉约束

角色沿用 Demo/V2 低面数、明确块面、克制色彩的 ASTRA 档案舱视觉。人类基础脸直接保留 Quaternius 原始皮肤、眼睛和眉毛网格；外星人沿用同一骨架和材质，但使用十种独立解剖头型（含保留的灰裔），并非作者原包自带的物种。配件在 Blender 中建模和绑定，进入 Unity 后只选择模块和修改形态键权重。

本版避免上一版通过缩放头部骨骼、运行时堆叠脸部零件实现脸型的方式。头骨和身体骨架不随捏人选项改变，脸宽、下颌及体型都限制在较小范围。脸型会同步影响头发、头饰、面饰和纹样，降低宽脸后眼镜悬空的问题。

## 操作层级

`新建角色 → 人类 / 外星人 → 大类 → 子项 → 样式`

| 大类 | 子项 |
| --- | --- |
| 身份 | 名字、唯一 ID；运行版另有预设角色列表 |
| 面容 | 人类脸型 / 外星人生物头型、眼睛、眉骨、鼻部 / 嗅觉器官、口部 / 口器 |
| 头部 | 人类：短发、分缝刘海、长发束发、帽饰；外星人：鳍膜叶瓣、角环骨板、触须感官 |
| 身形 | 体型、整体比例 |
| 装扮 | 上装、下装、鞋靴、面饰、装备、纹样 |
| 配色 | 肤色、发色、服装色、眼色、强调色 |

每次只展开当前子项；预览始终保留。角色素材库另按“物种 → Demo V2 原角色 / 捏人预设 / 自建角色”分组，支持按名字和 ID 搜索。选中项有色块和文字标记，不能仅靠色相表达状态。

Unity 编辑器修改的是草稿，点击保存才写回角色资产。重复 ID 拒绝保存，防止不同角色相互覆盖。Prefab 记录角色资产引用，运行时重新应用材质属性块；不为每次肤色变化复制整套材质。

## 模块组合

服装三部分使用原作者的模块化连接边界。默认预设采用成套上装、下装、鞋靴，策划可以分别更换。面饰或头盔遮住脸属于主动装扮选择；应在面部特写和侧面确认轮廓。长衣、背包、护肩与大幅度动作仍需按最终组合检查，有限测试不能覆盖所有排列。

源包属于 stylized modular men，V2 没有把有限体型变化宣传为完整性别、年龄或写实身体系统。外星人以直立 Humanoid 为边界，未把爬行体强行套入人类动作。

## 演出使用

工作台建议检查顺序：无面饰正面 → 侧面 → 全身待机 → 说话 → 坐姿说话 → 维修 → 触头 / 舞动。近景关注眼睛是否被脸部遮住、发际线和面饰接触；全身关注肩部、肘部、手指和服装模块接缝。

站桩演出默认无根运动，走路、慢跑等片段原地播放。需要场景走位时由上层演出控制角色根节点，并单独设计接触位置。坐姿动作仅改变人体姿势，实际项目须配高度相符的椅子；拿取和维修同样需要匹配道具及接触点。此版不把原地动画误称为物体交互 IK 系统。

跨动作使用短混合，拖动时间轴时结果必须可重复。默认动作栏只展示 17 个常用语义动作，底层可调用其余免费动画。动作不改变角色形态数据。

镜头从 V2 的全景、中景、近景、双人、过肩、侧面、低机位、设备插入和全身跟拍扩展。近景应随姿态适当修正高度；构图变化较大的切换用切镜，避免摄影机穿过角色。新角色发布前必须检查矮身高 / 高颅冠组合，不能只以标准人类头像作为验收样本。
