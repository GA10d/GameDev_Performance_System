# 演出草稿与一键导出

策划可以先在窗口中配置内容，在保存或导出时由工具自动生成文件。无需在 Project 中逐个创建 Package、Graph 和 Unit。

## 从零制作

1. 打开 Tool V2 的 Unity 工程，菜单 **Astra Performance Tool V2 → Open timeline**。
2. 点击窗口顶部 **新建演出**，选择单人来电、双人对话、交互问答、纯播报或空白演出，选好角色并填写台词后点击 **创建演出**。工具自动准备时间轴、入口和结束节点；此时不产生新的 Assets 资产文件。详见 [演出模板使用说明](演出模板使用说明.md)。
3. 将人物、动作、台词、镜头和场景拖到时间轴，在右侧配置内容。
4. 点击 **+ 新增单元** 添加下一段。普通 `next` 航路会自动插入新单元；原节点含选择分支时，需要在演出树中手动连接新节点。
5. 点击 **演出树** 编辑判断、全局选择和结束节点。演出树和时间轴共享当前演出包；选中演出节点会同步时间轴单元，也可点 **编辑此单元时间轴**。
6. **验证/校验** 检查配置；**运行预览** 播放当前整棵树，包括草稿的交互分支。进入播放前 Unity 可能询问是否保存当前修改的场景；退出播放会恢复原来的场景。不会把当前演出写回示例预览场景。
7. 点击 **导出到游戏**，填写演出名称、工程内保存目录、演出包 ID 和外部导出目录，点击 **保存并导出**。

例如演出名称 `MyMeeting`、ID `my_meeting`，默认工程目录下自动生成：

```text
Assets/AstraToolV2/Performances/MyMeeting/
  MyMeeting.asset
  MyMeeting_Graph.asset
  Units/
    Unit_1.asset
    Unit_2.asset
```

单元的文件名由工具管理；时间轴里填写的单元 ID、台词和所有配置都会保留。遇到同名演出会创建新的目录，不覆盖已有资产。

## 已经配好的内容

- 要继续修改已有演出：在顶部演出包选择框打开它，修改后点击 **保存** 或 **导出到游戏**。
- 要把当前配置作为独立新演出：点击 **复制为新演出**。演出树和单元均复制到草稿，角色、动作等公共素材继续复用，修改副本不会改变原演出树或单元。
- 演出树中 **+ 演出单元** 会同时准备对应单元内容，不再要求先在 Project 中创建 Unit。
- 编辑已保存演出时，新增加的单元会自动保存到它旁边的 `Units` 目录。

## 保存、恢复和导出的区别

- **草稿**：没有正式资产路径。每隔约 3 秒及脚本重载、正常退出前，在本工程 `Library/AstraPerformanceDraft.asset` 保存恢复缓存。重新打开编辑窗口时自动恢复。删除 Library 会清除这些草稿缓存；长期保留请点击保存。
- **保存**：允许保存未完成的配置，自动生成成套 Unity 资产，便于继续编辑。只保留一份活动草稿；切换到其他演出或再次新建时，会询问保存、取消或放弃。
- **导出到游戏**：先校验完整演出及 End 节点，再保存并导出整个依赖集合。取消或校验失败不会把草稿清掉。成功导出后记住该演出的 ID 与输出目录。

导出目录中的整个 `Assets` 文件夹（含 `.meta`）需要合并到游戏 Unity 工程；会议包自动放在 `Resources/Performances/<ID>.asset`。在星图编辑器中创建“视频会议 / Tool V2 演出树”事件，填写相同 ID，再重新构建游戏。导出操作本身不会自动修改星图或构建游戏。

原来的 `Create → Astra → Performance Tool V2` 菜单仍可使用，但策划日常流程不再需要它。原来的全工具 Unity 包导出菜单也保留；时间轴的 **导出到游戏** 专门导出当前演出及其依赖。
