# Tool/V2 外星人重设计与 Quaternius 原包发型

更新：2026-09-25。交付目录：`Tool/V2`。这次调整针对头型差异小、颅冠轮廓不明显、人类长发为圆弧发片的问题。

## 调研与设计取舍

| 官方参考 | 可学习的设计方法 | 本版采用的抽象方式 |
| --- | --- | --- |
| [No Man’s Sky NEXT 角色自定义](https://www.nomanssky.com/next-update/) | Gek、Vy’keen、Korvax 等族群在头身比例和整体轮廓上有明确差别 | 先改变颅骨的宽高、口鼻突出程度和眼睛布局，再制作局部选项 |
| [Halo 官方 Sangheili 造型讨论](https://www.halowaypoint.com/news/silver-debrief-unmasked) | 分裂下颚使口部成为物种识别点 | 原创四瓣折弯颚体，保留 ASTRA 的少面数实体块面，不提取游戏模型 |
| [Stellaris Plantoids](https://www.paradoxinteractive.com/games/stellaris/add-ons/stellaris-plantoids-species-pack) | 植物生命可用叶、瓣和枝条组织头部 | 花萼面盘、叶瓣冠、感光触须；使用几何厚度而非透明贴片 |
| [Stellaris Caelum](https://www.paradoxinteractive.com/games/stellaris/news/caelum-update-available-now) | Fungoid、Plantoid、Lithoid 提供不同于哺乳类脸部的物种方向 | 菌盖与径向鳃褶、棱柱晶面、不同材料感的冠部结构 |
| [Quaternius Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) | 发型由有体积的分缝、发束、发梢与髻构成 | 直接导入免费 Standard 包的头发网格，保留拓扑并适配现有头部 |

上表中的“采用方式”是本项目的设计归纳。外星人是新制作的低模网格，没有使用上述商业游戏的模型、贴图或角色名称。配色保持低饱和绿、褐、骨色和少量强调色；黑色眼部、清晰剪影与 ASTRA 服装材质沿用现有工具风格。

| ID | 名称 | 识别点 |

| 0 | 灰裔原型 | 保留原来的大眼窄下颌头部 |

| 3 | 穹壳独眼 | 圆穹头壳、单一大眼 |
| 4 | 横翼四目 | 横向展开的上颅、四只眼睛 |
| 5 | 菌伞胞族 | 细长面部、宽菌盖、盖下径向鳃褶 |

这是 10 个独立头网格（包含保留的灰裔），不是同一个头颅的十次轻微拉伸。仍为直立 Humanoid；没有把身体转换为四足或额外肢体生物。

## 颅冠与层级

`新建外星人 → 头部 → 类别 → 具体颅冠`

| 类别 | 选项 |
| --- | --- |
| 鳍膜叶瓣 | 无冠、宽鳃扇、背帆冠、菌褶伞冠、叶瓣冠 |
| 角环骨板 | 回卷角、月环骨冠、晶簇冠、叠甲冠、横桥骨冠 |
| 触须感官 | 垂落头触须、感光触须 |

共 12 个选项，包含无冠。差异来自宽膜、回卷曲线、竖向帆面、镂空圆环、下垂体积、伞盖、晶簇、长触须、叠片、叶瓣和横向桥骨，而非改变尖刺数量。为各头型制作 `AlienFit01–09` 适配形态键，统一处理宽度、高度和前后偏移。

配件边界：九种新解剖头型暂提供“无面饰 / 护颈”，灰裔原型保留原有眼镜、呼吸器等面饰。菌伞和花萼头型没有独立眉骨选项。新头型使用自身鳃纹、甲板或花瓣配色，暂不套用旧人脸位置的纹样。菜单会解释这些限制，避免显示无效控制。

外星人的配色页使用“颅冠基色”代替人类的“发色”。颅冠骨架与皮肤可独立染色，鳍膜、晶簇和花瓣局部由“强调色”控制；新建角色默认颅冠基色与皮肤相同。

人类头部选项共 **33 个，包含无发与 3 个帽盔**。现有编号保留；22、23、27 更新外观，30–32 追加。旧短寸 ID 10 的头皮外扩修复继续保留。

适配只调整朝向、尺寸、局部长度及贴头位置；不删减原发束、不用新圆弧片替换。导入前后顶点与三角面数记录在 `Source/ubc_hair_manifest.json`，六个适配模块均保留原网格拓扑。移除导入文件自带的冗余骨架，将头发重新绑定到共享 Head 骨骼，再加入现有人类脸宽、下颌及脸型适配形态键。头发没有新增动力学模拟。

## 代码与资源结构

- `Tools/build_modular.py`：总构建入口，保留原模块、衣服、共享骨架、短寸回归检查，执行以下两段建模流程。
- `Tools/import_ubc_hair.py`：直接读取 CC0 发型 FBX，拓扑校验、头皮贴合与共享骨架绑定。
- `Tools/alien_design.py`：头颅、五官、实体颅冠、局部形态键和冠部适配键；输出模型清单。
- `ToolCreatorOptions`：两端共用的选项、分类、兼容能力和数据规范化。
- `ToolCharacterView`：依据物种和 faceShape 选择唯一头网格，设置形态键与颜色；不修改骨骼比例。
- `ToolPortraitBounds / ToolPortraitFraming`：读取实际采样后的蒙皮网格，按视角投影八角包围盒，考虑近侧角点深度，防止高冠和宽冠裁切。
- `ToolStage.Build(true)`：捏人用环绕检查布景，墙面位于全身镜头轨道之外，增加背面补光。正式演出仍用原布景。

模型共 **121 个模块、51 根共享骨骼**。UAL 仍通过原 Humanoid Avatar 和 Manual Playables 采样；新增头型和头发不需要另一条动画路线。保存格式继续使用已有 faceShape、hairStyle 等编号字段；旧外星人 1–9 的编号现在对应新解剖造型，载入后外观会按本次设计更新。

## 本次检查与证据

Blender 源文件、Unity 工程、Windows Player 和 unitypackage 同步交付。实际运行检查包括：

- 36 个角色 × 42 动作 × 3 采样点：4,536 组姿势，49,626,486 个蒙皮顶点检查。
- 10 种头型和 12 个颅冠的正、侧、背面；全部 120 组头型 / 颅冠组合；60 张极端比例动作图；36 张原包发型视图。
- 外星人头型 / 颅冠和人类新增发型的 JSON 保存载入。
- 镜头包围盒角点与场景遮挡检查；补查四个全身方向。初次实拍发现大颅冠背面镜头进入墙后，已修改预览布景及取景公式后复测。

实拍联系表位于 `QA/AlienSheets`；原图与日志位于 `QA/AlienFinal`、`QA/alien-player.log`。本轮通过程序驱动与人工查看实拍图检查模型；不把自动选中菜单冒充鼠标逐项点击验收，也不声称所有颜色、动作时刻与装扮排列均无穿插。
