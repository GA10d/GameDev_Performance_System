# Tool/V2 太空服装扩充与调研

版本：2026-09-25。交付目录：`F:\Documents\GitHub\GameDev_Performance_System\Tool\V2`。

本次在已有 Quaternius 模型上新增 **12 套、36 个可替换模块**。总计 22 上装、22 下装、22 鞋靴；共享模型从 121 增至 157 个模块，骨架仍为 51 根。原有服装编号 0–9、发型、面容和角色配方保持原含义。

## 使用方法

运行 `RunToolV2.cmd`，选择人类或外星人，进入 **装扮 → 上装 / 下装 / 鞋靴 → 用途分类 → 样式**。Unity 内的捏人窗口提供相同分组。

| 用途分类 | 内容 |
|---|---|
| 原有服装 | 0–9，原来的航行服、工程服、休闲服等 |
| 舰内勤务 | 驾驶、医疗、舰桥、行商 |
| 舱外探索 | 加压、测绘、隔离、低温、热区 |
| 工业安保 | 采矿、拆解、舰队安保 |

点击样式只替换当前部位。**整套应用**把当前部位对应套装的上装、下装、鞋靴一起穿上；**使用推荐配色**单独修改服装色与强调色。换装不自动重置肤色、头部、体型或配饰。各类选项仍可混搭，保存的 JSON 使用原来的 V2 格式。

## 游戏调研与设计取舍

以下区分来源事实与本项目设计归纳。我们借鉴用途和造型组织方式，自行制作几何；没有导入商业游戏模型、贴图或标识。

| 参考与可核实信息 | 本项目的设计归纳与应用 |
|---|---|
| 《Starfield》美术负责人在 Xbox 官方文章中将 NASA-Punk 描述为有现实依据、易于理解的科幻美学。[官方访谈](https://news.xbox.com/en-us/2022/02/17/exclusive-signed-starfield-art-giveaway/amp/) | 舱外加压服采用可读的胸前控制盒、领环、袖口和靴口；驾驶服把装备收紧到躯干，方便区分飞行员与舱外工种。保留 ASTRA 的低饱和色块和粗糙低模表面。 |
| 《Star Citizen》的 Caldera 官方设定分别讨论严寒、酷热环境防护、储物和内衬，旗舰为 Novikov / Pembroke 环境服。[Caldera 官方文章](https://robertsspaceindustries.com/en/comm-link/spectrum-dispatch/18016-Portfolio-Caldera) | 低温服强调厚领、鼓起的分段胸垫；热区服强调浅色护面、横向散热条和深色连接区。这里的隔热、散热是视觉设定，没有增加温度数值系统。 |
| 《Elite Dangerous》开发者的 18.08 更新按 Maverick、Artemis、Dominator 区分服装承载能力；Maverick 的储物容量较高。[官方更新公告](https://store.steampowered.com/news/posts/?appids=359320&enddate=1723724684&feed=steam_community_announcements) | 用口袋、设备位置、护甲厚度表达职业差异。测绘服用轻装与单侧设备；拆解服用非对称防护；安保服用对称装甲。此行是对功能区分的设计推导，不是逐件复刻游戏外观。 |

ASTRA 以人物对话演出为主，因此把信息集中在中近景可见的肩、胸、袖口，同时让裤袋、护膝和靴子在全身镜头中可读。没有新增大背包、整脸遮挡头盔或动态软管，以减少坐姿穿插和异形头部适配负担。已有头盔、背包等仍在原有选项中。

## 模型与代码接入

- `Tools/space_outfits.py`：新增服装的生产脚本，由 `Tools/build_modular.py` 调用；从原始 CC0 衣服复制网格和蒙皮，重塑体积，再并入原创附件。`SPACE_OUTFITS` 保留编号、名称与原件来源。
- 服装模块使用现有 `Q_Suit`、`Q_Dark`、`Q_Ivory`、`Q_Accent` 等材质。人类、外星人共用身体骨架，裸露皮肤仍读取角色肤色。
- 硬质肩甲、护膝、鞋头分别绑定现有上臂、小腿、脚骨。束带按脊柱区段拆开；衣摆和背标转移原衣料或腿部权重。没有新 Armature、没有新的骨骼缩放，也没有更换 Humanoid / UAL / Playables 路线。
- 新裤腿下沿统一到约 0.125 m，新靴筒上沿约 0.275 m；腰部维持原接口。它们是模型 T Pose 空间中的制作约束，用来保留混搭重叠范围。
- 新部件在主构建脚本中统一获得 `Body01`–`Body07` 体型形态键，标准体型为 Basis。人体手部的既有校正仍只执行一次。
- `ToolCreatorOptions.cs`：22 套名称、用途 ID 分组、整套应用、推荐配色，以及按数组长度归一化和随机选择。未来加服装时追加 ID，不插入原编号。
- `ToolWorkbench.cs` / `ToolV2CharacterCreatorWindow.cs`：两端分层 UI。运行版根据当前分组长度计算滚动高度。
- `ToolOutfitRuntimeQA.cs`：`-outfitQA` 启动真实工作台的服装回归。`ToolV2QA.cs` 的混搭编号也改为使用 `Outfits.Length`。
- `ToolV2Build.BuildPlayer` 新增可选 `-toolBuildDir <绝对路径>`，允许在当前预览程序运行时构建到另一个目录；默认仍是 `Build/`。

全部生成模型仍落在 `Source/Quaternius_Astra_Modular.blend` 和 `UnityProject/Assets/AstraToolV2/Models/ModularCast.fbx`。这两个是本轮更新后的成品；直接手改生成 Blend 会在下次重建时被覆盖，后续资产投放方法见[目录指南](资产扩充与目录指南.md)。

## 验收范围与边界

检查记录、修复项及结果见[服装验收](太空服装验收.md)。服装名称表达 ASTRA 中的职业与用途；本轮新增的是换装与演出资产，没有实现生命维持、战斗护甲数值、氧气或布料物理。长衣摆采用分腿蒙皮，保留低模折面；极端姿势和任意配饰组合仍需要针对实际镜头复核。
