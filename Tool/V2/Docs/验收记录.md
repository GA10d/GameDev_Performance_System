## 检查发现并修正的问题

1. Blender 镜像修改器在形态键导出时未烘焙，导致腿、鞋只剩一侧：改为生成形态键前应用镜像，同时增加双侧顶点范围检查。
2. 对带厘米缩放的 SkinnedMeshRenderer 重复计算单位：修正检查器 BakeMesh 的缩放处理。
3. 硬法线使脸部表面过于碎裂：保留原低模拓扑，为头部设置合理的表面法线。
4. 高发型 / 颅冠在固定特写中容易被裁切：按当前头部与头饰包围盒自动取景。
5. 旧信号效果 Shader 使用 HLSL 保留字：修正后重新构建。
6. 编辑衣服仍停留面部特写：服装与体型分类自动切换全身；面饰回到特写。
7. 浮动捏人面板可能出屏：新建 / 编辑时检查窗口范围并恢复可见位置。
8. 演出树修改节点 ID 后连接丢失：同步更新入口和已有连线。
9. 时间轴双人预览只显示一个人物：增加同一时段人物的实例与相同动画采样。
10. 双人 / 过肩镜头缺少交流朝向：外层角色节点负责相向站位，Humanoid 骨骼保持动画所有权。

## 交付边界

- 验收覆盖预设、每种模块、部分极端组合和实际交互；不能据此宣称任意上百万排列都不存在局部穿插。尤其长衣、帽子、背包与极限姿态，仍需按最终角色检查。
- 人类脸型采用有限形态键，外星人采用独立头网格与局部形态键，并非任意雕刻系统；没有写实口型、语音同步、布料物理或完整手部接触 IK。
- 工作台坐姿提供参考凳。正式演出中的拿取、维修、坐姿，需要策划配置匹配的实际场景道具；动画片段本身没有自动生成道具。
- 新建只开放人类与直立外星人；半兽人以原 Demo/V2 角色保留；不把本版称为四足爬行体捏人器。
- 独立程序保存 JSON 外观，Unity 面板保存正式角色资产和 Prefab。Windows 字体使用本机字体回退，不分发系统字体文件。
