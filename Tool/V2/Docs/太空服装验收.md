# 太空服装验收

日期：2026-09-25。范围：Tool/V2 服装 ID 10–21，当前人类 / 站立外星人共用身体管线。

## 检查方法

使用 Unity 2022.3.62f1 实际构建 Windows 工作台，运行 `-outfitQA`。相机图像来自程序里的真实角色、UAL 动画、场景和材质；不是 Blender 静态摆拍。人工查看正 / 侧 / 背、坐姿和维修等实拍图，再修正模型并重新构建、采集。

## 本轮检查中修复

1. 原始太空裤与西装鞋的衔接高度不同：新裤腿下沿与新靴筒统一留出混搭重叠范围。
2. 背部识别条原先依赖固定坐标，侧面有悬浮感：根据原衣料表面射线贴合，并继承邻近原网格蒙皮。
3. 坐姿近图中部分胸前设备、行商腰袋离布面过远：附件后壁延伸至布面，并继承原蒙皮，避免身体弯曲后脱离衣服。
4. 轻装裸臂款袖环过宽：按基础衣料类型缩小袖环半径。
5. 服装编号原来限制在 0–9：上装 / 下装 / 鞋靴统一改为根据选项表长度限制，随机组合与分类注册同步扩充。

## 验收边界

数值回归检查骨骼和顶点有效性，不等同于逐三角形碰撞检测。新衣服没有布料物理；衣摆按左右腿分别蒙皮，某些极端姿势会有硬折面。已检查主要镜头和关键姿势，没有穷举每一帧、每一种颜色、全部上下装排列及所有旧背包 / 面饰叠加组合。

隐藏窗口的四张整屏截图仍会得到黑图，不作为 UI 通过证据，不纳入最终截图集；上面的菜单证据是原生窗口捕获。Unity 编辑器端已经同步分类实现并编译通过，本轮没有逐个鼠标点击全部编辑器选项。

## 复现

先按 README 重建，随后在 Tool/V2 目录执行：

```powershell
& '.\Build\ASTRA Performance Tool V2.exe' -outfitQA -qaDir "$PWD\QA\OutfitFinal" -screen-fullscreen 0 -screen-width 1440 -screen-height 900 -logFile "$PWD\QA\outfit-player.log"
# 等待程序自行结束，查看 outfit-runtime-result.txt。
python '.\Tools\outfit_sheets.py'
```

联系表脚本需要 Pillow 和 Windows 微软雅黑字体；仅用于生成 QA 图片，不参与 Unity 运行。新增服装后要扩展脚本中的名称清单。
