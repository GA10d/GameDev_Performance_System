# V2 发型更新 · 2026-09-25

## 内容

- 人类新增 18 款，发型 / 帽饰从 12 增至 30 个选项（含无发、3 个帽盔）；外星人原有 12 个颅冠选项保留。模块总数从 91 增至 109。
- 短发：圆寸、平头、短碎发、前刺短发、后梳短发、短卷发、宽莫西干。
- 分缝刘海：左侧分、右侧分、中分短发、齐刘海、斜刘海。
- 长发束发：短波波头、齐颈直发、低马尾、高马尾、盘发、双髻。
- 独立工作台和 Unity 编辑器采用同一套四组发型分类，避免所有样式挤在一起；切入头部分类时自动显示当前发型所属分组。

## 短寸修复

旧版 ID 10 将原短发的 Z 坐标压缩到头皮内部，头顶因此露皮。现在从原作者头皮网格裁出发帽，保持向外的厚度和闭合边缘，再与头部应用相同的脸型、脸宽、下颌形态键。重建脚本增加 10 个脸型 × 3 个宽度/下颌组合的头皮覆盖检测：2,160 条射线通过，最小间隙约 1.39 mm（模型原始单位）。

多数新增发型沿用 Quaternius 的实体发束改型；马尾、发髻、后发片、卷发和宽冠在 Blender 合并并蒙皮。仍用原材质、共享 51 骨骼、Humanoid / UAL / Playables 动作，未增加运行时骨骼缩放或发丝物理。

原有 ID 0–11 不变，新增 ID 为 12–29。Normalize、随机生成、JSON、角色资产保存与分类索引均按实际物种选项处理。旧角色无需迁移。
