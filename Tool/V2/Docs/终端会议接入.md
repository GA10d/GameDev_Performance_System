# 终端会议接入

`Samples/Meeting/RelayMeeting.asset` 是可用现有时间轴和演出树编辑器修改的示例包。它会导出到 Project-Astra 的终端会议播放器。

选中任意 ToolPackage 后使用菜单 `Astra Performance Tool V2 / Export selected package for cabin meeting`，导出的 Assets 目录包含依赖与共享运行时代码。也可以在 Project-Astra/3D Demo 运行 `SyncPerformance.ps1 -Package <资产路径> -PerformanceId <英文ID> -Build` 完成同步与构建。

演出节点的 End 发出 Completed 回调；空出口和跳转超限会报告失败，不会伪装为结束。默认独立 ToolPlayer 仍显示原界面；嵌入会议的实例使用 externalClock、showGUI 和 presentationLayer。

示例首次缺失时创建，重新导出不会覆盖已有示例编辑。详细使用和验收位于 Project-Astra/3D Demo/Source/performance_meeting.md。
