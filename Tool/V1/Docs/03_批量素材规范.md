# 批量人物与动作素材规范

## 输入清单

角色批量生产建议以一行一个角色的 CSV/JSON 清单管理：稳定 `id`、显示名、种族、源 `.blend/.fbx`、材质槽、骨架配置、头部高度、前向轴、地面基准、许可来源、截图路径。美术可以在 `Source/Astra_Six_Species.blend` 的六人原型基础上变更部件并重新导出。新角色进入材料库前必须确认 Blender 的比例和 Unity 的朝向、命名骨骼、零姿态与四足脚触点。

针对外部库，Quaternius、Kenney 或其他低模包可作为候选输入，但应先记录具体包名、版本、来源 URL、许可证和作者，再在隔离目录中检查比例、蒙皮、骨架、材质与再分发要求。此工具交付包实际使用 V3 原创模型，不把候选库误写成已集成资产。

## 转换步骤

1. Blender 中规范模型朝向和米制单位；四足与直立型分别用模板骨架。保留面部/服饰材质槽，不把所有可配置区域烘焙成同一材质。
2. 导出 FBX，命名与角色 id 对齐。自动检查必要骨骼、顶点权重、负缩放、法线、包围盒和地面穿插。
3. Unity 导入设置固定为相同版本；为肤色、制服、头发分配 V3 风格材质。仅用颜色替换无法弥补拓扑差异，外星人长颅与半兽人肩颌仍需要网格改造。
4. 每个新种族在 17 动作表中声明哪些动作可用；不支持时提供明确替代动作，不在演出中悄悄变成人类坐姿。V2 Quaternius Clip 若要用于新模型，需要 Humanoid Avatar 映射或 Blender 重定向并做人工复查；当前 V3 为自有命名骨架，因此本工程选用程序化动作语义。
5. 自动生成九镜头 contact sheet，检查头顶、手势、四足、尾巴和字幕安全区。对身高差设置独立相机高度，不只改 FOV。
6. 将通过验收的 Prefab、材料、动作与镜头录入 `ToolLibrary`，用演出单元与图表做回归；保留每个素材的来源与许可证记录。

批量生成可以减少重复劳动，但轮廓、服装叙事、表情可读性、动作接触点及镜头节奏仍需逐项人工验收。资产来源以 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 为准。
