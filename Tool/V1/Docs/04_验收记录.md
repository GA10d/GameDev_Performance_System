## 策划使用与画面复核（2026-09-25）

针对“选项堆在一起”和人物画面问题，捏人窗口改为 **六个大类 → 子项 → 单组选项**；人物库改为 **物种 → V3 原角色 / 捏人预设 / 自建角色**，加入搜索。新建入口与搜索框固定在列表上方。选中项有明确标记，子项切换后滚动回顶部。预览标题增加深色底，播放器字幕改为深底浅字（静态色值计算对比度约 16.7:1），多选项和较长台词按窗口宽度及文本高度排版。

视觉复核修正了短发发块悬空、窄脸时附件不随头部比例变化、宽眼距位置过高，以及直立外星人特写时颅冠触及画面顶部。最终在**实际 `Tool` 工程**执行 Unity 2022.3.62f1 的 `BuildPlayer`：退出码 0，`TOOL_VERIFY_OK 46`，`TOOL_BUILD_OK`。运行构建后的 Windows 播放器，重新生成并检查 32 名人类/外星人角色的 64 张正面与侧面图，以及原演出与九种镜头的 15 张图；角色、动作与分支捕获均正常。可快速查看 [角色正面总览](../QA/CreatorScreenshots/contact_sheet_front.png)、[侧面总览](../QA/CreatorScreenshots/contact_sheet_profile.png) 和 [镜头总览](../QA/LegacyScreenshots/contact_sheet.png)。用户已有的示例 A 人物轨 `actor0` 和场景、镜头设置保持原样。

编辑器窗口的逐项点击、拖拽与文字实屏仍未完成自动交互验收：远程桌面控制授权超时；隐藏模式下 Unity 的整屏截图为黑屏。因此菜单层级与编辑器文字可读性依据布局代码和 Unity 编译检查，播放器字幕依据色值和布局计算；上述 79 张截图是相机渲染画面，不包含 IMGUI 控件。
