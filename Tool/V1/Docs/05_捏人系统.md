# ASTRA 捏人系统：设计、使用与实现

## 使用流程

在 Unity 2022.3.62f1 中打开 `Tool/UnityProject`，选择 **Astra Performance Tool → Open timeline**。人物库顶部点击 **＋ 新建角色**，再选 **人类** 或 **外星人**。捏人窗口先选左侧六个大类之一（身份、面容、头部、身形、装扮、配色），再在顶部选子项，最后在内容区选具体样式。每次只显示一个子项的选项，切换时滚动位置会回到顶部。右侧实时预览支持十七种动作、旋转及缩放。点击 **保存角色与 Prefab** 后，角色立即出现在人物库，可以拖入人物轨。以后选中该角色，点击 **打开捏人编辑器** 可继续修改。

人物素材库先按物种展开，再按 **V3 原角色 / 捏人预设 / 自建角色** 展开；搜索框可按名字或 ID 查找。新建按钮和搜索框始终位于列表上方，长名单向下滚动时也能直接使用。

另可使用 **Astra Performance Tool → New character → Human / Alien**。预制角色保存在 `Assets/PerformanceTool/Characters`，对应 Prefab 在其 `Prefabs` 子目录。菜单 **Seed creator cast** 会幂等补齐 16 名人类、16 名外星人预设，不覆盖自行创建的角色。

## 选项与美术准则

| 类别 | 人类 | 外星人 | 实际表现 |
|---|---:|---:|---|
| V3 底模 | 3 | 1 | 复用现有 FBX 骨架与蒙皮 |
| 脸型 | 10 | 10 | 头骨比例、面颊、颌、眉脊 |
| 眼型 | 12 | 12 | 大小、角度、间距、瞳孔、额外眼睛 |
| 眉、鼻、口 | 各 8 | 各 8 | 眉骨、鼻或呼吸孔、口或呼吸缝 |
| 发型 / 颅冠 | 16 | 16 | 发束、侧发、顶髻；颅脊、角、鳍、触须、晶冠 |
| 体型 | 8 | 8 | 胸骨比例与整体身高微调 |
| 服装 | 12 | 12 | 背心、围裙、束带、肩甲、领饰等 |
| 面部 / 装备配饰 | 各 12 | 各 12 | 护目镜、面罩、头灯、工牌、终端等 |
| 面部纹样 | 8 | 8 | 伤痕、颊纹、额纹 |
| 肤、发、衣色 | 各 16 + 自定义 | 各 16 + 自定义 | ASTRA 低饱和、哑光配色 |
| 眼、强调色 | 各 12 + 自定义 | 各 12 + 自定义 | 可辨识的五官与道具重点 |

界面借鉴《模拟人生 4》的身体、头发和配饰分组及随机组合，以及《魔兽世界》的面部、眼色、发色、肤色等细分选项，但所有几何和配色重新适配 ASTRA 的低模像素感、工业档案舱和克制色调。参考：[EA《模拟人生 4》玩法介绍](https://www.ea.com/games/the-sims/the-sims-4/how-to-play-the-sims)、[Blizzard 人物自定义选项介绍](https://worldofwarcraft.blizzard.com/en-us/news/23537372)。

## 技术结构

- `ToolCharacterLook` 保存各部件索引与色彩，`ToolCharacter` 引用 V3 源模型及 `ToolCreatorResources`。原六角色的 `creatorEnabled` 默认为 `false`，维持原有外观。
- `ToolCreatorBuild` 在 Editor 中生成低面数网格、两种共享材质、32 份角色 `.asset` 和 Prefab。所有组合使用同一套几何资源，避免为每一种组合复制网格文件。
- `ToolCharacterView` 实例化原 V3 FBX。捏人角色仅隐藏源发、眼、嘴的材质子网格，再调用 `ToolCreatorGeometry` 在 `Head`、`Chest` 骨骼下生成替换部件；源 FBX 的骨架、蒙皮、材质资产均不写回。部件位置与尺寸随头部或胸部的比例变化，避免窄脸时眼睛跑到脸外。部件使用 `MaterialPropertyBlock` 着色，避免共享材质互相污染。
- `ToolMotion.Bind` 在外观生成之后缓存同一套 V3 骨名，因此 V2 的 17 项动作语义、时间轴预览、运行时播放和 Unity 包导出仍走原动作管线。头、胸附件会跟随骨骼，而不是另做独立动画。
- 新角色的 ID 在材料库中检查唯一性，保存后自动加入 `ToolLibrary.characters`。重新创建示例工程会保留用户捏出的角色。

新增部件偏向读得清的轮廓和色块，而非写实曲面。为降低动画穿插，脸宽与身高微调限在 ±15%，体型选项的胸骨比例在较小范围内；帽、发束、配饰只挂在其对应骨骼上。极端角度或动作接触仍应在右侧动作试演与实际镜头中逐项检查。

## 扩展及验收

新部件选项需同时加入 `ToolCreatorOptions` 的名称数组和 `ToolCreatorGeometry.Apply` 的几何分支，保证列表中的每一项都有可见效果。新增物种需要 V3 相同的命名骨骼和适配的面部锚点；爬行外星人保持现有独立动作，不自动作为直立角色的底模。

运行 **Astra Performance Tool → Verify and export package** 会校验所有角色的关键骨骼、捏人资源、头部附件和每角色 17 项动作姿态。`QA/CreatorScreenshots` 用前视与侧视图检查所有预设的脸、发型、服装、饰件是否穿插或被遮住。示例场景及原有六角色继续参加原演出/镜头验收。
