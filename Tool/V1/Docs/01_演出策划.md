# 演出策划：从素材到互动演出

## 目标与视觉规则

场景保持 Project Astra 的旧设备、灰绿漆面、低模人物、暖色工作灯和信号故障气质。工具要让策划能快速组合一段“人物出现—动作—台词—镜头—环境—选择”，再通过演出树串联多段。观众应始终看清主角面部与手势，能够辨别沉默、资源不足和明确选择所产生的不同结果。

本工程的六人名单为林、赫、余、弦（站立外星人）、砾（半兽人）、伏（四肢爬行外星人）。三名异种沿用 V3 原创造型；不把它们当作普通人类换皮。伏的机位通常更低、更宽，须容纳尾部及四只着地肢。与 V2 对照的动作菜单保留十七项，镜头菜单保留九种标准镜头并增自定义。

## 三阶段工作流

**素材准备。** 角色面板修改脸宽、体型、肤色、制服色、发色、帽型和配饰；导出独立角色 Prefab。动作列表展示时长和循环属性，悬停显示动作预览。镜头库包含全景、中景、近景、双人、过肩、侧面、低机位、设备插入、跟拍；特效有信号撕裂、干扰和紧急灯。场景库含档案舱、旧中继站、故障警报。动作和镜头必须和人物体型相配，尤其不要给伏安排双足坐下或拍胸。

**演出单元。** 人物轨决定角色在场时间；动作轨的每段必须完整落在某个人物片段中，空白部分自动待机。文字时长按字数÷每秒字数＋停留时间计算；选择应是该单元最后一段台词，超时走沉默出口。镜头与场景可独立覆盖不同时间段，缺镜头时使用保守全景。片段移出单元时长、无主体、文本重叠或未知素材都应在导出前报错。鼠标拖片段调整节奏，右侧检查器精确输入。导出单元 `.asset` 后可在另一张演出树复用。

**演出树。** 演出节点串行；判断节点读取全局资源；选择节点按条件显示可用选项，选择后增减资源；没有回应时消耗耐心并走沉默出口。全局选择可以承接多个前驱，也可以继续连向另一个全局选择，形成复合对话。所有出口应明确连接。样例的“维修券”与“供电”展示不同机制：券不足时支付不可选，供电不足时条件节点转向另一路演出。

## 逐镜与交互验收重点

| 场景 | 演出重点 | 易错点 |
|---|---|---|
| 弦提出中继请求 | 中景见手势，近景突出迟疑和信号故障 | 头部被字幕或画框裁切；故障遮住按钮 |
| 砾维修中继 | 跟拍交代空间，低机位突出体型与维修动作 | 手穿过柜体；跪姿低于画框 |
| 伏回应 | 足够宽的跟拍与侧面，四肢和尾部有余量 | 用人类眼高导致伏太小或看不到脚 |
| 每个选择 | 文案、可用性、耐心倒计时、沉默结果可理解 | 按钮相叠、资源不足仍可点击、选择后重复扣费 |
| 九种镜头 | 主体明确，设备插入确实对准设备 | 过肩镜头没第二人时构图显得空；不同体型套同一偏移 |

镜头在动作转折或台词信息变化时切换；信号特效宜集中于转折一两秒，不应持续掩盖面部。选择出现前留足阅读时长，沉默的节奏要让玩家感到有意而非程序丢失输入。站桩演出依赖微动作、镜头视线和环境光变化来维持生命感，而非频繁大幅位移。
