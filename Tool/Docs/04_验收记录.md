视觉复查中发现并修复：播放器构建后指示灯 Shader 被裁剪造成舞台初始化失败；跨单元重用相同人物轨 ID 导致后续段落继续显示上一位角色；隐藏窗口屏幕抓取全黑；站立外星人近景顶部过紧、四足侧面过度裁切、单人使用双人/过肩镜头时构图偏空；舞台正面缺光和随后补光过强。最终截图已重新生成。`ToolCapture` 使用相机 RenderTexture 保存 3D 画面，避免隐藏播放器的黑屏缓冲。
